mission "Main Plot Plus Check"
    invisible
    non-blocking
    landing
    to offer
        has "chosen sides"
        not "main plot plus: enabled guided start"
    on offer
        set "global: main plot plus: does not need guided start"
        fail
mission "Main Plot Plus Prompts"
    invisible
    non-blocking
    landing
    on offer
        conversation
            `Welcome to Main Plot Plus! I am JamesGPT. As an AI language model, it is my job to help you configure Main Plot Plus the way you want. To assist you in this effort, I have compiled several presets for you. Which one would you like to use?`
            choice
                `(Enable default features)`
                    to display
                        or
                            has "global: main plot plus: enabled guided start"
                            has "global: main plot plus: enabled security analysis jobs"
                            has "global: main plot plus: enabled paint trim jobs"
                            has "global: main plot plus: enabled main plot soft block"
                            has "global: main plot plus: enabled main plot skip"
                            has "global: main plot plus: enabled navy license mission"
                    goto default
                `(Enable recommended features)`
                    goto recommended
                `(Enable vanilla+ features)`
                    goto vanillaplus
                `(Enable all features)`
                    goto all
                `(Enable no features)`
                    goto none
                `(Do not use any of these presets)`

            # No preset
            `Got it. I will ask you about each feature, one at a time.`
            `First, would you like to enable guided start? This allows you to pick a side or neutrality, sets all necessary conditions in order to do so, and helps you navigate to the right location. This will trigger in 3017 if you have not chosen a side.`
            choice
                `(Enable guided start)`
                `(Disable guided start)`
                    goto noguide
            action
                set "main plot plus: enabled guided start"
            `Alright, I have enabled guided start.`
                goto security
            label noguide
            `Alright, I have disabled guided start.`
            label security
            `Next, would you like to enable security analysis jobs? These allow you to check your armament deterrence, cargo attraction, and local reputation in most planets that have job boards. This is information you normally are unable to see, so choose wisely.`
            choice
                `(Enable security analysis jobs)`
                `(Disable security analysis jobs)`
                    goto noanalysis
            action
                set "main plot plus: enabled security analysis jobs"
            `Alright, I have enabled security analysis jobs.`
                goto paint
            label noanalysis
            `Alright, I have disabled security analysis jobs.`
            label paint
            `Now, would you like to enable paint trim jobs? These allow you to change the swizzle of your ship. This will take up a lot of spaces in the job board, and you can change your mind through the job board at any time. I recommend only enabling this, changing your color, then disabling this, unless you plan to frequently change your color.`
            choice
                `(Enable paint trim jobs)`
                `(Disable paint trim jobs)`
                    goto nopaint
            action
                set "main plot plus: enabled paint trim jobs"
            `Alright, I have enabled paint trim jobs.`
                goto sethidden
            label nopaint
            `Alright, I have disabled paint trim jobs.`

            label sethidden
            `Would you like me to mark all systems as hidden if the main plot has not been completed? This makes it so you can only see systems if they are linked to a system you are in, marked by a mission, or visited by the player. The main reason to do this is to make the game feel more immersive and to encourage completing the main plot first. Certain mods, like Shields Up, may add additional systems to the game. These systems will also be hidden if the mod is supported.`
            choice
                `(Mark systems as hidden)`
                `(Do not mark systems as hidden)`
                    goto nohidden

            action
                set "main plot plus: enabled main plot soft block"

            `Alright, I have marked all systems as hidden. The systems I have marked as hidden will be unhidden when the main plot is completed.`
                goto setskip

            label nohidden
            `Alright, I have not marked additional systems as hidden.`

            label setskip
            `Would you like to enable a short mission chain that allows you to skip the main plot? There are a few missions that try to make sense lore wise, but for the most part, this basically only skips the main plot, and is mainly intended for quick debugging of changes caused by completing the main plot.`
            choice
                `(Let me skip the main plot)`
                `(Do not let me skip the main plot)`
                    goto noskip
            action
                set "main plot plus: enabled main plot skip"
            `Alright, I have enabled the short mission chain that lets you skip the main plot.`
                goto setnavy

            label noskip
            `Alright, I have disabled the short mission chain that lets you skip the main plot.`

            label setnavy
            `Would you like to enable a short mission chain that grants you the navy license after you complete the main plot?`
            `Since you have Lost in Midnight installed, you can already get the navy license, so you probably don't need this.`
                to display
                    has "installed plugin: Lost-in-Midnight"
            choice
                `(Let me get the navy license)`
                `(Do not let me get the navy license)`
                    goto nonavy

            action
                set "main plot plus: enabled navy license mission"
            `Alright, I have enabled the short mission chain that grants you the navy license. You can do it once you complete the main plot.`
                goto setpreset

            label nonavy
            `Alright, I have disabled the short mission chain that grants you the navy license.`

            # Save default features
            label setpreset
            `Finally, would you like to save these settings as the default preset, so that you can reuse them on other saves without having to go through this process? Note that this will completely override the previous default preset if you had one.`
            choice
                `(Yes)`
                `(No)`
                    goto nopreset
            branch guidepreset
                has "main plot plus: enabled guided start"
            action
                clear "global: main plot plus: enabled guided start"
            branch noguidepreset
            label guidepreset
            action
                set "global: main plot plus: enabled guided start"
            label noguidepreset
            branch securitypreset
                has "main plot plus: enabled security analysis jobs"
            action
                clear "global: main plot plus: enabled security analysis jobs"
            branch nosecuritypreset
            label securitypreset
            action
                set "global: main plot plus: enabled security analysis jobs"
            label nosecuritypreset
            branch paintpreset
                has "main plot plus: enabled paint trim jobs"
            action
                clear "global: main plot plus: enabled paint trim jobs"
            branch nopaintpreset
            label paintpreset
            action
                set "global: main plot plus: enabled paint trim jobs"
            label nopaintpreset
            branch hiddenpreset
                has "main plot plus: enabled main plot soft block"
            action
                clear "global: main plot plus: enabled main plot soft block"
            branch nohiddenpreset
            label hiddenpreset
            action
                set "global: main plot plus: enabled main plot soft block"
            label nohiddenpreset
            branch skippreset
                has "main plot plus: enabled main plot skip"
            action
                clear "global: main plot plus: enabled main plot skip"
            branch noskippreset
            label skippreset
            action
                set "global: main plot plus: enabled main plot skip"
            label noskippreset
            branch navypreset
                has "main plot plus: enabled navy license mission"
            action
                clear "global: main plot plus: enabled navy license mission"
            branch nonavypreset
            label navypreset
            action
                set "global: main plot plus: enabled navy license mission"
            label nonavypreset
            `Got it. I have made your chosen settings the default preset.`
                to display
                    or
                        has "global: main plot plus: enabled guided start"
                        has "global: main plot plus: enabled security analysis jobs"
                        has "global: main plot plus: enabled paint trim jobs"
                        has "global: main plot plus: enabled main plot soft block"
                        has "global: main plot plus: enabled main plot skip"
                        has "global: main plot plus: enabled navy license mission"
                goto end
            `Got it. Since you disabled all features, I have cleared the default preset.`
                to display
                    not "global: main plot plus: enabled guided start"
                    not "global: main plot plus: enabled security analysis jobs"
                    not "global: main plot plus: enabled paint trim jobs"
                    not "global: main plot plus: enabled main plot soft block"
                    not "global: main plot plus: enabled main plot skip"
                    not "global: main plot plus: enabled navy license mission"
                goto end
            label nopreset
            `Got it. I have not updated the default preset.`
                to display
                    or
                        has "global: main plot plus: enabled guided start"
                        has "global: main plot plus: enabled security analysis jobs"
                        has "global: main plot plus: enabled paint trim jobs"
                        has "global: main plot plus: enabled main plot soft block"
                        has "global: main plot plus: enabled main plot skip"
                        has "global: main plot plus: enabled navy license mission"
                goto end
            `Got it. I have not set the default preset.`
                to display
                    not "global: main plot plus: enabled guided start"
                    not "global: main plot plus: enabled security analysis jobs"
                    not "global: main plot plus: enabled paint trim jobs"
                    not "global: main plot plus: enabled main plot soft block"
                    not "global: main plot plus: enabled main plot skip"
                    not "global: main plot plus: enabled navy license mission"
                goto end

            # Use default features
            label default
            branch nodefaultguide
                not "global: main plot plus: enabled guided start"
            action
                set "main plot plus: enabled guided start"
            label nodefaultguide
            branch nodefaultsecurity
                not "global: main plot plus: enabled security analysis jobs"
            action
                set "main plot plus: enabled security analysis jobs"
            label nodefaultsecurity
            branch nodefaultpaint
                not "global: main plot plus: enabled paint trim jobs"
            action
                set "main plot plus: enabled paint trim jobs"
            label nodefaultpaint
            branch nodefaulthidden
                not "global: main plot plus: enabled main plot soft block"
            action
                set "main plot plus: enabled main plot soft block"
            label nodefaulthidden
            branch nodefaultskip
                not "global: main plot plus: enabled main plot skip"
            action
                set "main plot plus: enabled main plot skip"
            label nodefaultskip
            branch nodefaultnavy
                not "global: main plot plus: enabled navy license mission"
            action
                set "main plot plus: enabled navy license mission"
            label nodefaultnavy
            `Got it. I have enabled the default features.`
                goto end

            # Use recommended features
            label recommended
            branch smart
                "days since start" > 0
            action
                set "main plot plus: enabled main plot soft block"
            `Got it. I have enabled the recommended features.`
                goto smart

            # Use vanilla+ features
            label vanillaplus
            `Got it. I have enabled the vanilla+ features.`
            label smart
            branch recommendeddone
                "days since start" > 0
            branch midnight
                has "installed plugin: Lost-in-Midnight"
            action
                set "main plot plus: enabled navy license mission"
            label midnight
            branch recommendeddone
                has "global: main plot plus: does not need guided start"
            action
                set "main plot plus: enabled guided start"
            label recommendeddone
            branch end

            # Use all features
            label all
            action
                set "main plot plus: enabled guided start"
                set "main plot plus: enabled security analysis jobs"
                set "main plot plus: enabled paint trim jobs"
                set "main plot plus: enabled main plot soft block"
                set "main plot plus: enabled main plot skip"
                set "main plot plus: enabled navy license mission"
            `Got it. I have enabled all features.`
                goto end

            # Use no features
            label none
            `Got it. I have enabled no features.`

            label end
            `Thank you for using JamesGPT. Have a nice day!`
                decline
